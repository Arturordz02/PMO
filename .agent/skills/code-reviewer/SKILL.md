# Skill: Revisor de Código y Clean Code

## Propósito
Revisar y auditar código para garantizar que cumpla con los estándares de producción, seguridad y mejores prácticas de arquitectura.

## Instrucciones para Antigravity
Cuando el usuario solicite revisar, auditar o refactorizar un archivo o módulo:
1. Inspecciona el código buscando violaciones a los principios SOLID y Clean Code.
2. Identifica vulnerabilidades de seguridad (como inyección SQL o falta de sanitización de inputs).
3. Detecta problemas de rendimiento o posibles fugas de memoria.
4. Genera un resumen de los problemas encontrados y entrega el código refactorizado y listo para producción.
