# Skill: Despliegue en Servidores y Optimización Web (DevOps)

## Propósito
Preparar, minificar y desplegar proyectos web en entornos de producción (cPanel, Vercel, Netlify, Apache).

## Instrucciones para Antigravity
Cuando el usuario solicite ayuda para subir la web a un servidor o dominio:
1. Verifica la compatibilidad de rutas relativas de activos (`img/`, `css/`, `js/`).
2. Sugiere optimizaciones de carga (minificación de archivos, compresión de imágenes, caché de navegador).
3. Configura redirecciones SSL (HTTP a HTTPS) y parámetros de archivo `.htaccess`.
