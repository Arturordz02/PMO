# Skill: Diseñador de Pruebas Unitarias

## Propósito
Crear pruebas unitarias e integrales para verificar la estabilidad de los módulos antes de desplegar o presentar entregables.

## Instrucciones para Antigravity
Cuando el usuario solicite pruebas unitarias o validar una lógica:
1. Identifica los casos de uso principales y los casos de borde (edge cases) del módulo.
2. Diseña pruebas unitarias aisladas con aserciones claras (Assertions).
3. Asegura que el código sea testeable y sugiere refactorizaciones si las funciones están sobrecargadas.
