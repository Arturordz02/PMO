# Skill: Generador de Documentación Técnica

## Propósito
Generar documentación técnica clara, estructurada y profesional en Markdown para informes universitarios y sustentaciones de prácticas.

## Instrucciones para Antigravity
Cuando el usuario pida documentar un proyecto o explicar la arquitectura de un módulo:
1. Crea una estructura clara con introducción, arquitectura del sistema y flujo de componentes.
2. Diseña diagramas visuales de flujo o secuencia utilizando la sintaxis de **Mermaid.js**.
3. Agrega una sección llamada "Sustentación Técnica", detallando la justificación del diseño usado para facilitar exposiciones académicas y profesionales.
