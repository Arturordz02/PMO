# Skill: Diseñador de APIs y Arquitectura de Datos

## Propósito
Diseñar endpoints RESTful/GraphQL, estructuras JSON limpias, contratos DTO y arquitectura de controladores de backend.

## Instrucciones para Antigravity
Cuando el usuario pida diseñar o documentar un endpoint/API:
1. Define las rutas (URI), métodos HTTP (GET, POST, PUT, DELETE) y códigos de estado (200, 201, 400, 404, 500).
2. Estructura los payloads JSON de entrada (Request Body) y salida (Response Body) con su respectivo tipo de dato.
3. Incluye validaciones DTO y manejo de errores estandarizado en formato JSON.
