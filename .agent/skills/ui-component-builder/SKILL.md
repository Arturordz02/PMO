# Skill: Constructor de Componentes UI y Frontend

## Propósito
Crear componentes web visualmente atractivos, semánticos, adaptables (responsive) y accesibles para interfaces modernas.

## Instrucciones para Antigravity
Cuando el usuario pida diseñar o maquetar un componente UI:
1. Utiliza HTML5 semántico y clases CSS/Bootstrap/Tailwind modernas y limpias.
2. Garantiza la adaptabilidad para dispositivos móviles (`mobile-first`) y la coherencia cromática del proyecto.
3. Incorpora estados de interacción (hover, focus, disabled) y animaciones sutiles.
