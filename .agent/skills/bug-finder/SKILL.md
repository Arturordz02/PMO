# Skill: Detector y Corrector de Bugs

## Propósito
Escanear código en búsqueda de errores de sintaxis, variables nulas, referencias no encontradas y fallos de ejecución.

## Instrucciones para Antigravity
Cuando el usuario reporte un error o pida depurar un archivo:
1. Identifica la causa raíz del error o excepción reportada.
2. Revisa asignaciones de variables `null`/`undefined`, bucles infinitos y problemas de asincronía (`async/await` / Promesas).
3. Entrega el diagnóstico breve del fallo seguido de la corrección exacta del código.
