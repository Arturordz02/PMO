# Skill: Optimizador de Consultas SQL y Bases de Datos

## Propósito
Diseñar esquemas relacionales, escribir consultas SQL eficientes, optimizar JOINs y crear índices para alto rendimiento.

## Instrucciones para Antigravity
Cuando el usuario pida crear o refactorizar consultas SQL o modelos de bases de datos:
1. Aplica reglas de normalización (1FN, 2FN, 3FN) según el caso de uso.
2. Escribe consultas SQL seguras contra inyección SQL utilizando sentencias preparadas (Prepared Statements).
3. Recomienda el uso de índices, claves primarias/foráneas y optimizaciones para evitar barridos completos de tabla (Table Scans).
