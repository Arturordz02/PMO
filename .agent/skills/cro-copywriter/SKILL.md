# Skill: Copywriting de Alta Conversión (CRO) y Ventas

## Propósito
Redactar textos comerciales persuasivos y optimizar elementos de conversión (CTAs, microcopys) para captación de clientes.

## Instrucciones para Antigravity
Cuando el usuario pida mejorar textos de banners, modal o botones de ventas:
1. Utiliza disparadores mentales de urgencia, valor profesional e impacto directo.
2. Formatea llamadas a la acción (CTAs) claras orientadas a WhatsApp o inscripción directa.
3. Adapta el tono al perfil corporativo B2B / B2C de la empresa sin perder elegancia.
